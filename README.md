## About STYLiSH
STYLiSH is an E-Commerce website providing a seamless shopping experience.
> [!NOTE] 
The project is deployed on Firebase. You can access the [live version](https://appworkschool-project1.web.app/homepage.html) here.

## Features
- Shopping Cart: Users can add products to the cart, modify quantities, and see the total price.
- Checkout: Users can fill in their payment information and submit the form to complete the purchase.
- Login: Users can log in using Facebook for profile validation.
- Product Scroll: Infinite scrolling to load more products as the user scrolls down.
- Get JSON from API: Fetch product data and other information from a REST API.
- Responsive Design
